How I Evaluate Engineers

Engineering Character Sheets

This is my framework for evaluating engineers before I consider an organization's own leveling framework.

Every engineer gets a sheet: six attributes, five levels, and a score for each attribute that ties to a real example. Their class is the role they play, like product, data or platform engineer. Class and level are separate: any class can reach any level.

House Rules

  1. Set goals: The next cell to the right is the goal.
  2. Give feedback: Every score ties to a cell and a real example.
  3. Validate my vibes: A scorecard to test my hypothesis about an engineer.
